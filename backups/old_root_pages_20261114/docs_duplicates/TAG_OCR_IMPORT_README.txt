5S SMART | ALUMET — รับ Tag จากภาพถ่ายและเติมข้อมูลอัตโนมัติ

ติดตั้ง Patch:
1. สำรองโปรแกรมเดิมก่อน
2. แตก ZIP นี้ลงใน htdocs โดยคงโครงสร้างโฟลเดอร์
3. เปิดหน้า รับ Tag / ปิด Tag 5 ส.
4. เปิดรายการเดิมด้วยปุ่ม แก้ไข หากเป็น Tag ที่มีอยู่แล้ว หรือเริ่มรายการใหม่
5. เลือกรูปแบบฟอร์ม Tag ต้นฉบับ (JPG/PNG/WEBP ไม่เกิน 5 MB) แล้วกด อ่านภาพและเติมข้อมูลอัตโนมัติ
6. ตรวจและแก้ไขช่องที่อ่านผิด จากนั้นกดบันทึก

OCR ใช้ Tesseract.js ผ่าน CDN จึงต้องมีอินเทอร์เน็ตขณะอ่านภาพ และลายมือภาษาไทยอาจอ่านผิด โดยเฉพาะชื่อคน/จุดบกพร่อง/เครื่องหมายติ๊ก กรุณาตรวจทุกช่องก่อนบันทึก

ภาพฟอร์มต้นฉบับจะถูกเก็บแยกจากรูป Before/After ในคอลัมน์ source_photo แบบ additive migration โดยไม่ลบข้อมูลเดิม
ห้ามเขียนทับ db/database.sqlite หรือ uploads เดิมด้วยไฟล์สำรองจาก ZIP
