# Auditor 12 Month V39

ปรับเฉพาะหน้า auditor_12month.php ตามคำขอ:
- แต่ละรอบมี 3 สถานะ: ว่าง, ✓ มาตรวจ, ✗ ไม่มา
- กดช่องรอบตรวจเพื่อวนสถานะ ว่าง → ✓ → ✗ → ว่าง
- บันทึกสถานะลง SQLite ทันทีทุกครั้งที่กด
- ✓ เท่านั้นที่นับเป็นจำนวนครั้งและใช้คำนวณเปอร์เซ็นต์/กราฟ
- ✗ ใช้แสดงการไม่มา ไม่เพิ่มยอดตรวจ
- รายชื่อยังดึงจากแผนตรวจ 5 ส. โดยตรง
- ส่วนอื่นของระบบไม่ได้แก้ไข
