# Area Master / Department Master Update

## เพิ่มพื้นที่
- เมนู `แผนก / กลุ่ม / หน่วย` (`areas.php`)
- เพิ่มทีละหน่วยได้เหมือนเดิม
- เพิ่มหลายหน่วยพร้อมกันได้ เช่น `22,23,24`
- Production และ Office แยกฐานข้อมูลด้วยฟิลด์ `department`

## แก้ชื่อแผนก / Section
- ใช้กล่อง `เปลี่ยนชื่อแผนก / Section`
- เปลี่ยนชื่อทั้งชุดของประเภทนั้น (Production หรือ Office)
- ปรับ `areas.group_name` และชื่อพื้นที่ที่สร้างจากชื่อแผนก
- ปรับชื่อใน `audits.group_name` และ `excel_monthly.group_name` เพื่อให้รายการอ้างอิงแสดงชื่อใหม่สอดคล้องกัน
- ไม่ลบคะแนนหรือประวัติการตรวจ

## ลด/ลบพื้นที่
- ปุ่ม `ลบ` เดิมยังทำงาน
- ถ้ามีประวัติการตรวจ ระบบจะเปลี่ยนเป็นปิดใช้งานแทน เพื่อรักษาคะแนนย้อนหลัง
- สามารถเปิดใช้งานกลับได้

## การใช้งานกับใบตรวจ
เมื่อเลือกประเภท + แผนก ระบบใบตรวจจะดึงเลขหน่วยที่ active ของแผนกนั้นอัตโนมัติ และไม่รวมพื้นที่ของ Office เข้ากับ Production หรือกลับกัน
