คู่มือปรับปรุง: ภาพรวมคะแนนทุกกลุ่ม Production + Office

ไฟล์ที่เพิ่ม:
- graph_overview.php: หน้าแสดงภาพรวมทุกหน่วยจากทั้ง Production และ Office ในกราฟเดียว

ไฟล์ที่ปรับ:
- index.php: เพิ่มปุ่มเข้าไปยังหน้าภาพรวมทุกกลุ่ม
- includes/header.php: เพิ่มเมนูในแถบด้านข้างและเมนูมือถือ

พฤติกรรม:
- ใช้เดือน/ปีเป็นตัวกรองร่วมกันทั้งสองแผนก
- แสดงหน่วยที่เปิดใช้งานทั้งหมดจาก Master แม้เดือนที่เลือกยังไม่มีคะแนน
- หน่วยที่ไม่มีคะแนนแสดงเป็นสีเทา พร้อมข้อความ “ยังไม่มีคะแนน” และรายการแยกตามแผนก
- สีเขียว/แดงเปรียบเทียบตามเป้าหมายเฉพาะแผนก
- ไม่มีการแก้ไขหรือลบข้อมูลในฐานข้อมูลจากหน้าภาพรวม

วิธีติดตั้งอย่างปลอดภัย:
1. สำรองโปรแกรมเดิมก่อน
2. คัดลอกเฉพาะ index.php, graph_overview.php และ includes/header.php ไปยังโฟลเดอร์แอปที่ใช้งานจริง
3. อย่าเขียนทับ db/database.sqlite, uploads หรือ backups ด้วยข้อมูลจาก ZIP หากต้องการคงข้อมูลเครื่องปัจจุบัน
4. เปิด Dashboard แล้วคลิก “ภาพรวมทุกกลุ่ม (Office + Production)” และกด Ctrl+F5 หากยังเห็นหน้าเดิม

หมายเหตุ: ตรวจ syntax PHP ผ่านแล้ว แต่สภาพแวดล้อมที่จัดทำไฟล์นี้ไม่มี PDO SQLite ใน PHP CLI จึงยังไม่สามารถทดสอบการเรนเดอร์จริงด้วย PHP CLI ได้ ควรยืนยันอีกครั้งบน XAMPP เครื่องใช้งานจริง
