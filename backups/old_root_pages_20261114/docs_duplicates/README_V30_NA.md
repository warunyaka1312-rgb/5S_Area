# V30.1 — N/A ไม่ได้ตรวจ

- ช่องที่เลือก N/A / ไม่ได้ตรวจ จะไม่ถูกนำไปรวมคะแนนและไม่เพิ่มคะแนนเต็มของข้อนั้น
- บันทึกสถานะ N/A ในฐานข้อมูลเพื่อเปิดกลับมาแล้วเห็นสถานะเดิม
- คะแนนรวมและ % คำนวณเฉพาะข้อที่ตรวจจริงและมีคะแนน
- ช่องว่างที่ยังไม่ลงคะแนนยังแสดงเป็น ยังไม่มีคะแนน ไม่ถือเป็น N/A จนกว่าจะเลือก N/A
