5S SMART | ALUMET - Tag Quick Form Update

ปรับหน้า tag_manage.php ให้กรอกข้อมูลสั้นและง่ายขึ้น:
- Tag No. สร้างอัตโนมัติจากหมายเลขที่มีอยู่ โดยยังตรวจป้องกันหมายเลขซ้ำฝั่งเซิร์ฟเวอร์
- วันที่รับ Tag กำหนดเป็นวันที่ปัจจุบันอัตโนมัติ
- เลือกแผนกและหน่วยจากข้อมูลเดิม และเลือกชื่อผู้รับผิดชอบจากรายการชื่อที่มี
- รายละเอียดปัญหาเป็นช่องหลักที่ต้องกรอก
- ส่วน Corrective Action / Verification ยุบไว้ เปิดเมื่อเริ่มดำเนินการแก้ไข
- อัปโหลดรูป Before / After ได้หลายภาพ พร้อมคงรูปเดิมเมื่อแก้ไขแล้วไม่ได้เลือกรูปใหม่
- ข้อมูลระบบในรายการเดิมยังอ่านอย่างเดียว และคงวันที่ปิดเดิมเมื่อแก้ไขรายการ

ติดตั้ง:
1. สำรองโฟลเดอร์และฐานข้อมูลก่อน
2. แตก ZIP แล้วใช้โฟลเดอร์ 5S_V33_final_area_auto ตามชื่อเดิม
3. หากต้องการเก็บข้อมูลล่าสุดในเครื่อง ให้เก็บ db/database.sqlite และ uploads/tag_photos ของเครื่องเดิมไว้ ไม่เขียนทับด้วยไฟล์จาก ZIP
4. เปิด tag_manage.php แล้วกด Ctrl+F5

ข้อจำกัดสำคัญ:
ระบบต้นฉบับนี้ยังไม่มีการยืนยันตัวตน/บทบาทผู้ใช้แบบแยกแผนก จึงยังไม่ควรถือว่าช่องแก้ไขได้รับการป้องกันด้วยสิทธิ์จริง การจำกัดสิทธิ์รายแผนกต้องพัฒนาระบบ login/role เพิ่มเติมก่อนใช้งานจริง
