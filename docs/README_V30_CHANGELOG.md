# V30 แก้ไขจาก V29

1. Manual Production/Office เปลี่ยนเป็น 1 คนตรวจต่อ 1 ใบ และใช้คะแนนชุดเดียวกับ Import
2. Import Production บันทึกคะแนนแยกตามพื้นที่/หน่วยลง `audits` + `scores` ทำให้ Dashboard / Ranking / รายงานสัมพันธ์กับคะแนนจริง
3. แผนกใน Import เป็น "แผนก" เท่านั้น
4. เลขพื้นที่/หน่วยด้านบนกระดาษไม่ถูกอ่านเป็นคะแนน
5. ช่องไม่มีพื้นที่/ขีดไม่ถูกคิดเป็น 0
6. OCR ห้ามแปลงข้อความหลายหลัก เช่น 1734 เป็นคะแนน 1; ช่องไม่มั่นใจเว้นให้ตรวจเอง
7. Dashboard / Ranking / รายเดือน / รายปี เปลี่ยนจาก `excel_monthly` เป็นข้อมูลตรวจจริงใน `audits`/`scores`
8. เพิ่มหน้า `settings.php` สำหรับแก้เป้าหมาย เช่น 85%
9. สถานะและเส้นเป้าหมายใช้ค่าจาก settings เดียวกัน
10. Backup/Restore ยังใช้ได้ และ V30 มี migration แบบเพิ่มอย่างเดียวเพื่อไม่ลบข้อมูล V29
11. มี `unit_import_audits`, `unit_import_units`, `unit_import_scores` สำหรับเก็บประวัติไฟล์นำเข้า

## สำคัญ
การ OCR ลายมือไม่สามารถรับประกัน 100% ได้ ระบบจึงบังคับให้ตรวจค่าที่อ่านได้ก่อนบันทึก เพื่อป้องกันคะแนนผิดจากลายมือ
