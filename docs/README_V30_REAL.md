# 5S SMART Score System V30 — REAL USE

ติดตั้ง:
1. แตกโฟลเดอร์ `5S_Score_System_V30` ไปที่ `C:\xampp\htdocs\`
2. เปิด Apache ใน XAMPP
3. เปิด `http://localhost/5S_Score_System_V30/`
4. **อย่าลบ `db/database.sqlite`** หากนำ V30 ไปทับ V29 เพราะฐานข้อมูลเดิมถูกเก็บไว้แล้วในชุดนี้
5. ถ้าใช้ฐานข้อมูลจากเครื่องเดิม ให้สำรอง SQLite ก่อน แล้วค่อยแทนไฟล์/โฟลเดอร์

จุดที่แก้ใน V30:
- Manual Production/Office = 1 ใบ / 1 พื้นที่-หน่วย / ผู้ตรวจ 1 คน
- Import PDF Production = 35 ข้อ × สูงสุด 6 พื้นที่/หน่วย และบันทึกเข้าตาราง `audits` + `scores` ชุดเดียวกับ Manual
- Import จะสร้าง/จับคู่พื้นที่กับเลขหน่วย และผูกผู้ตรวจคนเดียวกันกับทุกหน่วยในใบ
- Dashboard / Ranking / รายเดือน / รายปี ดึงจากคะแนนที่บันทึกจริง ไม่ใช้ `excel_monthly` เป็นตัวหลัก
- เป้าหมายแก้ได้ที่เมนู `ตั้งค่าเป้าหมาย` และใช้ร่วมกันทุกหน้า
- ช่องไม่มีการตรวจ/ขีด ไม่ถูกนับเป็น 0
- OCR ไม่ยอมแปลงตัวเลขหลายหลัก เช่น 1734 ให้เป็นคะแนน 1; ช่องไม่มั่นใจจะเว้นว่างให้ตรวจภาพจริง
- เก็บไฟล์ต้นฉบับใน `uploads/`
- Backup SQLite และ JSON ใช้ได้
- ประวัติ Manual และ Import ใช้ฐานข้อมูลเดียวกัน

ข้อจำกัด OCR:
- การอ่านลายมือไม่สามารถรับประกันความถูกต้อง 100% ได้ จึงต้องตรวจตารางก่อนบันทึก
- แบบ Production ใช้พิกัด Cell ตามแบบที่ให้มา
- แบบ Office รองรับการนำเข้า/บันทึกโครงสร้าง แต่หน้า Import จะให้กรอก/ตรวจคะแนนด้วยมือ เนื่องจากตำแหน่งช่องของแบบ Office เป็นคนละ Template และไม่ควรเดาพิกัด

การสำรอง:
- ใช้ `backup.php` ก่อนอัปเดตหรือเปลี่ยนฐานข้อมูลทุกครั้ง
