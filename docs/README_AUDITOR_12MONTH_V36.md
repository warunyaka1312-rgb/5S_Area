# V36 — ผู้ตรวจ / ประวัติการตรวจ 12 เดือน

เพิ่มหน้า `auditor_12month.php` โดยไม่แก้โครงสร้างหน้าตารางแผนตรวจเดิม

## ความสามารถ
- เลือกปี
- เลือกทีม A / ทีม B / ทุกทีม
- รายชื่อผู้ตรวจเรียงลงมา
- เดือน ม.ค.–ธ.ค. เรียงแนวนอน
- ช่องรายเดือนเป็น checkbox ✓
- ถ้ามีการตรวจมากกว่า 1 ครั้งในเดือนเดียว จะแสดงจำนวนครั้งในช่อง
- รวมจำนวนครั้งรายคนอัตโนมัติ
- เปรียบเทียบรายชื่อผู้ตรวจด้วยกราฟ
- สรุปจำนวนครั้งรายเดือนด้วยกราฟ
- ดึงข้อมูลจริงจาก `audit_plans`
- เพิ่มชื่อ / แก้ชื่อ / ลบชื่อสำหรับทีมที่เลือก
- บันทึก checkbox ได้ทันที
- ใช้ตาราง `auditor_monthly_history` แบบเพิ่มเฉพาะส่วน ไม่ลบข้อมูลเดิม

## เปิดใช้งาน
หลังแตก ZIP เข้าโฟลเดอร์เดิม ให้เปิด:
`http://localhost/5S_V33_final_area_auto/auditor_12month.php`

หรือเลือกเมนู **ข้อมูลพื้นฐาน → ประวัติผู้ตรวจ 12 เดือน**

แนะนำให้กด **ดึงข้อมูลจากแผนตรวจ** ก่อนใช้งานครั้งแรกของแต่ละปี/ทีม
