5S SMART | ALUMET — V60 (ปรับเป็นระบบอัตโนมัติ + เชื่อมทุกหน้า + ดีไซน์สากล)
=====================================================================

ข้อมูลเดิมไม่ถูกแก้ไข: ไม่มีการเปลี่ยนตาราง คะแนน แผนตรวจ TAG หรือรูปภาพใด ๆ
(db/database.sqlite ใน ZIP ฉบับเต็มเป็นไฟล์เดิมจากที่ส่งมา ไม่ถูกแตะต้อง)

1) โลโก้ ALUMET ทุกหน้า
   - แถบด้านบน + เมนูซ้าย + ส่วนท้ายของทุกหน้าในระบบ
   - หน้าพิมพ์/เอกสาร: ใบตรวจ Production/Office, ใบตรวจเปล่า, พิมพ์กราฟ, แผนตรวจ,
     ใบลงชื่อ Auditor, ฟอร์ม TAG (เปล่า/จากข้อมูล), สรุป TAG, บอร์ดสรุป 3 เดือน, ป้ายบอร์ด 5ส.
   - Favicon (ไอคอนแท็บเบราว์เซอร์) เป็นสัญลักษณ์ ALUMET
   - ไฟล์: assets/alumet-logo.png (พื้นโปร่งใส), assets/alumet-logo-original.png (ต้นฉบับ)

2) ทุกหน้าลิงก์ถึงกันได้หมด
   - เมนูเดียวใช้ร่วมกันทั้งระบบ (includes/navigation.php) เพิ่มหน้าที่เดิมไม่มีในเมนู:
     ภาพรวมทุกกลุ่ม, พิมพ์กราฟ Production/Office, แบบลงชื่อ Auditor, จัดการพื้นที่/หน่วย,
     ตรวจพิกัดแบบฟอร์ม (OCR)
   - Breadcrumb (หน้าหลัก / หมวด / หน้า) + แท็บหน้าที่อยู่หมวดเดียวกัน ด้านบนทุกหน้า
   - ปุ่ม "ก่อนหน้า / ถัดไป" ท้ายหน้า ไล่ตามลำดับงาน
   - ค้นหาเมนูด่วน: กด Ctrl + K แล้วพิมพ์ชื่อหน้า (เช่น TAG, แผนตรวจ, Backup)
   - หน้าพิมพ์ที่เปิดแยกแท็บ มีแถบ "← กลับ / หน้าหลัก / พิมพ์" (ไม่แสดงตอนพิมพ์)
   - เมนูบนมือถือ/แท็บเล็ตเป็นแบบเลื่อนออกจากซ้าย

3) งานอัตโนมัติ (includes/automation.php)
   - สำรองฐานข้อมูลอัตโนมัติวันละ 1 ครั้ง -> backups/auto_daily_YYYYMMDD.sqlite (เก็บ 30 วันล่าสุด)
     ดู/ดาวน์โหลดได้ที่หน้า สำรอง / กู้คืนข้อมูล และมีปุ่ม "สำรองตอนนี้"
   - อัปเดตสถานะแผนตรวจจากคะแนนที่บันทึกจริง ทุก 10 นาที (เดือนนี้ + เดือนก่อน)
     เดิมทำเฉพาะตอนบันทึกคะแนน/เปิดบางหน้า
   - กระดิ่งแจ้งเตือนด้านบน: TAG เกินกำหนด, TAG ที่ยังเปิด, แผนตรวจวันนี้, แผนที่รอตรวจ
   - Dashboard มี "ศูนย์ติดตามอัตโนมัติ" กดแต่ละการ์ดเพื่อไปหน้าที่ต้องจัดการ
   - เปิดหน้าโดยไม่เลือกเดือน ระบบเลือกเดือนให้อัตโนมัติ:
       • แผนตรวจ -> เดือนปัจจุบัน (เดือนใหม่จะสร้างแผนจากเดือนก่อนให้เองตามระบบเดิม)
       • พิมพ์แผนตรวจ / ใบลงชื่อ -> เดือนล่าสุดที่มีแผน
       • กราฟ/Ranking, พิมพ์กราฟ, รายงานรายเดือน -> เดือนล่าสุดที่มีคะแนน
       (เดิมล็อกไว้ที่ กันยายน 2569)
   - เปิด/ปิด และสั่งรันทันทีได้ที่ ตั้งค่าเป้าหมาย / ระบบอัตโนมัติ
   - สถานะงานอัตโนมัติทั้งหมดดูได้ที่ ตรวจความพร้อมระบบ

4) ดีไซน์แบบสากล (assets/alumet-theme.css)
   - โทนสีองค์กร ALUMET (ส้ม-เหลือง + กรมท่า) พื้นขาวสะอาด ฟอนต์ Inter + IBM Plex Sans Thai
   - ไอคอนเส้นแบบเดียวกันทั้งเมนู, การ์ด/ปุ่ม/หัวข้อเป็นแบบเดียวกันทุกหน้า
   - ใช้งานได้แบบออฟไลน์: Tailwind, Chart.js, jQuery, DataTables, Alpine, html2canvas
     และฟอนต์อยู่ใน assets/vendor (ไม่ต้องต่ออินเทอร์เน็ต ยกเว้น OCR ในหน้านำเข้า/TAG)
