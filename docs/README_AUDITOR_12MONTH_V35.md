# V35 — ผู้ตรวจ / ประวัติ 12 เดือน
- เก็บข้อมูลผู้ตรวจครบ 12 เดือน
- ไม่แยกข้อมูลเป็น Team A / Team B ในหน้าประวัติ
- ชื่อผู้ตรวจเป็นช่องเลือก (select) และแก้ไขได้
- จำนวนครั้ง, วันที่ตรวจ และแผนกแก้ไขได้
- เพิ่มรายการใหม่ในแต่ละเดือนได้
- ปุ่มดึงข้อมูลจากแผนตรวจจะรวมข้อมูลผู้ตรวจโดยไม่แยกทีม
- ประวัติการตรวจจริงเดิมยังคงแสดงด้านล่าง
