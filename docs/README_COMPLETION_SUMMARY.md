# Monthly Completion Audit — 5S SMART | ALUMET

หน้า `completion_summary.php` ใช้ทวนสอบความครบถ้วนของการลงคะแนน 5ส. แยก Production / Office หรือดูรวมกันได้

- ค่าเริ่มต้นเลือกเดือนและปีปัจจุบันตามเวลา Asia/Bangkok
- เลือกเดือน/ปีใดก็ได้เพื่อย้อนดูผลการตรวจที่ผ่านมา
- มีคลังประวัติเดือนที่มีใบตรวจ พร้อมจำนวนหน่วยและจำนวนใบตรวจของ Production / Office และกดกลับไปยังรายงานเดือนนั้นได้
- เดือนที่ไม่มีใบตรวจจะแสดงคำเตือน และแสดงหน่วยที่ยังไม่มีใบตรวจในตาราง
- พิมพ์ A4 ได้ โดยซ่อนส่วนตัวเลือก/ประวัติเดือน และแสดงงวดที่พิมพ์ในรายงาน
- อ่านข้อมูลจาก `areas`, `audits`, `scores` และ `office_scores`; ไม่เพิ่มหรือเปลี่ยนแปลงตารางข้อมูลเดิม

ข้อจำกัดสำหรับประวัติ: ระบบใช้ Master ที่ Active ปัจจุบันเป็นฐาน และเพิ่มหน่วยที่มีใบตรวจในเดือนย้อนหลังเข้าในรายการคาดหวัง แม้ปัจจุบันจะปิดใช้งานแล้ว เพื่อเก็บประวัติที่ตรวจจริงไว้ อย่างไรก็ตาม ฐานข้อมูลเดิมไม่มีวันเริ่ม/สิ้นสุดการใช้งานของแต่ละหน่วย หากมีหน่วยที่ถูกปิดหรือย้ายก่อนเดือนที่ต้องการทวนสอบและไม่มีใบตรวจในเดือนนั้น ต้องตรวจสอบ Master/เอกสารแผนตรวจประกอบก่อนรับรองผลย้อนหลังอย่างเป็นทางการ
