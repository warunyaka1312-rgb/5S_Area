# สรุปภาพรวมองค์กร 5 ส. — กรกฎาคม / สิงหาคม / กันยายน 2569

อัปเดตเฉพาะหน้า `org_3month_summary.php` พร้อมข้อมูล Excel ที่ใช้สำหรับนำเข้าคะแนนย้อนหลัง ก.ค.–ส.ค. ข้อมูลเดือน ก.ย. อ่านจากใบตรวจจริงในฐานข้อมูลระบบ

## ติดตั้งโดยเก็บข้อมูลเดิม
1. แตก ZIP นี้
2. คัดลอก `org_3month_summary.php` ไปทับที่ `C:\xampp\htdocs\5S_V33_final_area_auto\org_3month_summary.php`
3. คัดลอกโฟลเดอร์ `data` ที่มี `history_comparison_3months_2569.json` ไปไว้ใน `C:\xampp\htdocs\5S_V33_final_area_auto\data\`
4. **ห้ามนำฐานข้อมูลจาก ZIP อื่นมาทับ `db/database.sqlite`**
5. เปิด `http://localhost/5S_V33_final_area_auto/org_3month_summary.php`
6. กด “นำเข้าข้อมูลย้อนหลัง ก.ค.–ส.ค.” เพื่อรีเฟรชคะแนนย้อนหลังสองเดือน ระบบสำรองรายการย้อนหลังเดิมก่อนแทนที่ ก.ย. ใช้คะแนนจริงและไม่ถูกเขียนทับ
