# V29 — Import แบบกระดาษ 6 พื้นที่/หน่วย

- ใช้โฟลเดอร์เดิม `5S_Score_System_V29`
- เลขด้านบนของตาราง = **พื้นที่/หน่วย**
- ตัวเลขในช่อง 35 แถวด้านล่าง = **คะแนน**
- รองรับ 35 ข้อ × 6 หน่วย
- เลือกไฟล์ครั้งละ 1 ไฟล์
- แสดงคะแนนให้ตรวจสอบก่อนบันทึก
- บันทึกลง SQLite ตาราง `unit_import_audits` และ `unit_import_scores`
- เก็บไฟล์ต้นฉบับใน `uploads/`
- Backup ใช้ `backup.php` เดิมได้ เพราะข้อมูลอยู่ใน SQLite
