# V29 Cell OCR

ปรับระบบนำเข้า PDF แบบฟอร์ม Production ให้แยกช่องคะแนนตามตำแหน่งจริงของแบบฟอร์ม

- 1 ใบ = ผู้ตรวจ 1 คน
- 35 ข้อ × 6 พื้นที่/หน่วย = 210 ช่อง
- เลขพื้นที่/หน่วยไม่ถูกนับเป็นคะแนน
- OCR ทำทีละช่อง ไม่ใช่ OCR ทั้งหน้าแล้วเรียงตัวเลข
- ทุกช่องถูกสร้างในตารางตรวจสอบ แม้ OCR อ่านไม่ได้จะเว้นว่างเพื่อให้แก้เอง
- รองรับ 0, 0.5, 1, 1.5, 2, 2.5, 3 และเครื่องหมายขีด
- บันทึก SQLite และ Backup ได้

หมายเหตุ: ลายมือในภาพสแกนอาจอ่านไม่ถูก 100% จึงต้องตรวจสอบก่อนกดยืนยันบันทึก
