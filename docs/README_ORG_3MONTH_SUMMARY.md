# สรุปภาพรวมองค์กร / เทียบ 3 เดือน

ไฟล์ใหม่: `org_3month_summary.php`
ข้อมูลต้นทาง: `data/history_comparison_3months_2569.json` (ถอดข้อมูลสรุปรายหน่วยจาก `เทียบ3เดือน.xlsx`)

## วิธีใช้
1. แตก ZIP ลง `C:\xampp\htdocs\` โดยรวมเข้ากับโฟลเดอร์เดิม `5S_V33_final_area_auto` ห้ามลบโฟลเดอร์เดิม
2. เปิด `http://localhost/5S_V33_final_area_auto/org_3month_summary.php`
3. กด `นำเข้าข้อมูลย้อนหลัง 3 เดือน` เพื่อ import มิถุนายน–สิงหาคม 2569 ไปยัง `excel_monthly`
4. ระบบสร้างไฟล์สำรองของข้อมูลย้อนหลังเดิมก่อนแทนที่ไว้ใน `backups/`

นำเข้าจาก Master ปัจจุบันด้วย `unit_no` เพื่อให้ประเภท/กลุ่มอ้างอิงตามข้อมูลจริง ไม่สร้าง audit หรือคะแนนรายข้อปลอม และไม่แก้ `audits`, `scores`, `office_scores`.

รายการจาก Excel ที่ไม่จับคู่กับพื้นที่ที่ active ใน Master จะไม่ถูกนำมานับในภาพรวมองค์กร และจะแสดงในข้อความผลนำเข้า
