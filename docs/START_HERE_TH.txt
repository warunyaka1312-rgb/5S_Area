5S SMART | ALUMET — คู่มือเริ่มต้นใช้งาน

1) สำรองโฟลเดอร์โปรแกรมเดิมและฐานข้อมูลก่อนติดตั้งทุกครั้ง
2) คงชื่อโฟลเดอร์โปรแกรมเป็น 5S_V33_final_area_auto
3) ตรวจว่า XAMPP เปิด Apache และ PHP มี PDO SQLite (pdo_sqlite) แล้ว
4) เปิด http://localhost/5S_V33_final_area_auto/ เพื่อเข้า Dashboard
5) เปิด http://localhost/5S_V33_final_area_auto/setup_check.php เพื่อตรวจความพร้อมและจำนวนข้อมูล
6) เริ่มจากข้อมูลพื้นฐาน > ตรวจแผนก/กลุ่ม/หน่วย จากนั้นบันทึกคะแนน Production และ Office แยกกัน
7) ใช้รายงาน/กราฟเพื่อติดตามผล และใช้ TAG เพื่อบันทึก/ติดตามการแก้ไข
8) สำรองข้อมูลก่อนนำเข้าข้อมูลหรือกู้คืนฐานข้อมูลทุกครั้ง

สำคัญ: ห้ามเขียนทับ db/database.sqlite, โฟลเดอร์ uploads และไฟล์สำรองจาก ZIP ลงบนข้อมูลจริงโดยไม่ตรวจสอบก่อน

หน้าเริ่มต้น: index.php (Dashboard)
หน้าตรวจความพร้อม: setup_check.php
URL เดิม: localhost/5S_V33_final_area_auto/
