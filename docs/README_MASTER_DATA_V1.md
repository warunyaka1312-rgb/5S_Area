# Master Data: แผนก / กลุ่ม / หน่วย

เพิ่มหน้า `master_data.php` สำหรับจัดการรายชื่อแผนกที่ใช้ร่วมกับหน้าตารางตรวจ 5 ส.

## สิ่งที่เพิ่ม
- เพิ่ม/แก้ไข/ปิดใช้งาน/เปิดใช้งานแผนก
- ดึงรายชื่อแผนกจาก `departments` และ seed จากข้อมูลเดิมใน `audit_plans`, `areas`, `excel_monthly`
- รายชื่อที่เพิ่มในหน้านี้จะถูกนำไปใช้เป็นตัวเลือกใน `schedule_manage.php`
- แสดงสรุปจำนวนแผนก กลุ่ม และหน่วย
- แสดงรายการกลุ่ม/หน่วยจาก `areas`
- ไม่ลบข้อมูลคะแนนย้อนหลังเมื่อปิดใช้งานแผนก
- เปลี่ยนเมนู "แผนก / กลุ่ม / หน่วย" ใน sidebar ให้เปิดหน้าใหม่
- หน้าจัดการพื้นที่เดิม `areas.php` ยังอยู่และเข้าถึงได้จากปุ่ม "จัดการพื้นที่ละเอียด"

## ไฟล์ที่แก้
- `master_data.php` (เพิ่มใหม่)
- `includes/header.php` (เปลี่ยนเฉพาะลิงก์เมนู)

ส่วนอื่นของระบบไม่ได้แก้ไข
